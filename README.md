# landing.hr – nova verzija (pregled)

Statična verzija stranice LAND ING d.o.o., generirana iz sadržaja postojećeg WordPressa.

- `content/site.json` – sav sadržaj (stranice, članci)
- `site/assets` – stil, skripta, slike
- `build/build.py` – generator (`python3 build/build.py .`), izlaz u `dist/`
- `docs/` – objavljena verzija (GitHub Pages)

Stranica ima `noindex` dok je u pregledu.
